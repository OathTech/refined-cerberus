## 2. The mirror design ([AGENT])

- **The file object is a parameter of the evaluator.** `evalPexpr`,
  `stepPexprRaw`, `stepPexpr`, `evalPexprList`, `evalPexprs` take `(file :
  generic_file Unit core_run_annotation)` after `ext`; every `Step`
  constructor's evaluator premise reads `evalPexpr M.tagDefs M.extern
  M.file ρ …`; `PassJoint tds ext file ρ pe` names the file. The engine
  bridges (`step_eval_bridge`, `aux2_bridge`, `full_eval_bridge`,
  `eval1_bridge`, `stepFail_bridge`) are re-established arm by arm with
  `{file}` theorem-level binders; the new arms are
  `call_function_of_callBody` (success) and
  `call_function_exception_of_callOut` (failure). This is the FORCED
  change of the slice: E2's `eval_uncovered` residual named "the mirror
  does not read the file"; E3's mirror does.
- **Static inlining budget.** `peDepth (PEcall nm pes) = 1 + peDepthList
  pes + stdBudget nm`, `stdBudget` keyed by the callee's printed name (the
  `SD_Id` string): `is_representable_integer ↦ 4`, `conv_int ↦ 17`,
  `conv_loaded_int ↦ 23`, every other name `0`. The budgets are the depths
  of the transcribed bodies (`peDepth_isReprBody = 4` etc., `rfl`;
  `stdBudget_le : stdBudget nm ≤ 23`). A callee whose body exceeds its
  budget is NOT unfolded (the classifier's `.uncovered`, a new face of
  `OpenRound.eval_uncovered` — the closure record). The measure keeps
  `peDepth` a well-founded measure for the joint induction and keeps the
  evaluator-fuel premises `≤ lemDefaultFuel` decidable at authored
  operands (`depLeC`/`depLe40`).
- **`peStrip`.** The engine returns the callee body with the annotations
  of the substituted arguments; the mirror strips the body's root
  annotations (`peStrip`, moved to Step.lean with arms for call/if/ctor
  operands) so that pass and strip commute (`peStrip_root_all`,
  `peDepth_peStrip_all`, `isPePure_peStrip_all`, `evalPexpr_peStrip`,
  `stepPexprRaw_peStrip`).
- **`PElet` WITHDRAWN** from E3's grammar: `pull_constrained` strips the
  let body, so the pass/strip invariance the joint induction needs fails
  at `PElet`; no std.core body E3 transcribes uses it after the strip
  (`conv_int`'s source has none; `conv_aux` is not transcribed). Budgets
  were recomputed after the withdrawal (4/17/23).
- **`is_unsigned` at a LEAF only** (`peDepth pe = 1`): the engine's
  non-value rebuild of `PEis_unsigned pe` is `PEis_scalar pe'`
  (core_eval.lem:1086 — the same rebuild as the three arms above it; a
  copy-paste in the model). At a leaf operand the rebuild never happens
  (one pass reaches the ctype), so the mirror is exact where it is
  defined; at a deeper operand the engine's result is `is_scalar`'s, which
  the mirror does not pretend to compute. Filed as an upstream-tray
  candidate in §7; NOT worked around.
- **Symbol identity.** `symbol_compare` compares digest and id only; the
  std symbols of `stdlibE3` use ids 9001–9017 (`Symbol "" 9001 (SD_Id
  "is_representable_integer")`, …). `stdBudget` reads the `SD_Id` string,
  so a corpus file's own `conv_loaded_int` symbol (whatever id the
  elaborator gave it) gets the same budget — the lookup in `file.stdlib`
  is by the file's symbols (`StdE3 file := file.stdlib = stdlibE3` fixes
  them to the transcription's).

2. **`is_unsigned` at a leaf only** (§2). The engine quirk is recorded,

   the kernel does not reduce the shipped driver (measured, §6). The
   whole run was MEASURED by compiled evaluation and is recorded
   verbatim; the theorem is the round at every fuel.
6. **The pure nodes of `progCE3` carry `[]` annotations** (as exhibit B's):

   elaborator's `{-# loc #-}` on a pure node is admitted by `Frag.pure_op`

7. **`stdBudget` keyed by the printed name** rather than by symbol:
   [AGENT] — the corpus's symbols carry elaborator-chosen ids; the file's
   `stdlib` is what resolves the call, the budget only bounds the
   unfolding. A name collision (a user function named `conv_int` in
   `funs`) would give the user's body the library's budget — the
   unfolding is still `call_function`'s (stdlib first), so no unsoundness;
   the budget might merely refuse an unrelated body (`.uncovered`).
8. **Main did not move**: `git rebase main` before the final gate was a
   no-op (main `04059dc` is an ancestor of the branch; the `e2-fixes`
   branch exists and is checked out in another worktree; it was not
