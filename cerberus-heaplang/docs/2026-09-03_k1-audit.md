## The questions

### Q1. The coupling — sound and complete for the flags

`MetaCoh` (Heap.lean:928-932, verbatim):
```
structure MetaCoh (σ : Mem) (id : Int) (mc : MetaCell) : Prop where
  live : mc.alive = true → LiveCoh σ id mc
  dead : mc.alive = false → σ.deadAllocations.contains id = true ∧
    σ.allocations.get? id = none
  nonAtomic : atomicTyOpt mc.ty = false
  dynamic : mc.dynamic = true → mc.addr ∈ σ.dynamicAddrs
```
`LiveCoh` (:915-919): `dead : σ.deadAllocations.contains id = false`,
`alloc : ∃ al, σ.allocations.get? id = some al ∧ al.base = mc.addr ∧ al.size = (mc.size : Int) ∧ al.ty = mc.ty ∧ (al.isReadonly = .IsWritable ↔ mc.readonly = false)`.

Against the engine's writers (all cites re-measured at the pin):

- `allocateObject` :1518-1519 (verbatim)
  `let alloc : Allocation := { base := alignedAddr, size := size, ty := some ty,` /
  `isReadonly := readonlyStatusForAlloc pref initOpt,`; :1521-1523 insert
  at `allocId := st.nextAllocId`, cursor drop; `dynamicAddrs` untouched.
  `readonlyStatusForAlloc` :1490-1492: `| none => .IsWritable`; the
  fragment's `create` is `Step.lean:1112` `applyMemM (CerbMem.allocateObject M.tagDefs 0 pref align ty none none) σ`
  (also :1528, :1681) — `initOpt = none`, so `.IsWritable`; checked also
  by `example (pref : prefix0) : readonlyStatusForAlloc pref none = .IsWritable := rfl`
  (accepted). `CreateReadOnly` (Core.lean:1004; `step_action`
  Core_reduction.lean:424 passes `some mval`) has 1 textual occurrence
  under `CerberusHeapLang/` and it is the header comment in Heap.lean
  saying it is not in the fragment; `Frag` has no constructor for it.
  So `live`'s `isReadonly` agreement holds for every cell the fragment
  mints: `CohG.create`'s new-cell case is `LiveCoh` at the record with
  `isReadonly := .IsWritable` and `objCell … true false`.
- `allocateRegion` :1544 (verbatim)
  `let alloc : Allocation := { base := alignedAddr, size := size, prefix_ := pref }`
  — no `ty`, no `isReadonly`; `Allocation` :112-113 (verbatim)
  `ty : Option ctype := none` / `isReadonly : ReadonlyStatus := .IsWritable`.
  So the record's `ty` IS `none` for regions and `al.ty = mc.ty` with
  `regionCell a n alive := ⟨a, none, n, alive, false, true⟩` is the right
  equality; `size := sizeN.toNat` (:1538) matches `n : Nat` cast to
  `Int` (zero admitted, per K0). :1548
  `dynamicAddrs := alignedAddr :: st.dynamicAddrs` gives the `dynamic`
  clause by `List.mem_cons_self` at mint.
- `killM` :1577-1578 (verbatim)
  `deadAllocations := allocId :: st.deadAllocations` /
  `allocations := st.allocations.erase allocId` — exactly `MetaCoh.dead`
  for the killed id (`(allocId :: _).contains allocId = true`, `erase`
  then `get? = none`); for `id' ≠ allocId`, `contains id'` and `get? id'`
  are unchanged and `dynamicAddrs` is not touched (`MetaCoh.of_fields`
  applies — the lemma exists, :939-948). `killM` READS `dynamicAddrs`
  (:1573) and never writes it, so `dynamic` survives the kill
  unconditionally, as the docstring says.
- `storeM` non-locking (:1667-1730): the active arm is `writeBytesTo`
  plus `funptrmap`/`lastUsedUnionMembers` — `MetaCoh.writeBytes`
  (`of_fields rfl rfl rfl`). Read-only kill :1725 (verbatim)

  state untouched. The locking arm :1689-1693 is the one writer of
  `isReadonly` — N-2.
- `loadM` (:1621-1665): no state change on the active arm.

Soundness: every clause is implied by the engine's tables at every
