## 4. THE RULE, verbatim (Rules.lean, Wps.lean, Wpt.lean)

```lean

    (kind : kill_kind) (pv : CerbMem.PointerValue) : CoreExpr :=
  Expr [] (Eaction (Paction polarity.Pos (Action loc ann
    (Kill kind (Pexpr [] () (PEval (Vobject (OVpointer pv))))))))

theorem kill_atomic [SpikeGS hlc GF] {M : MachineCtx}
    (loc : CerbLocation.Loc) (ann : core_run_annotation) (kind : kill_kind)
    (pv : CerbMem.PointerValue) (ty : ctype) (bs : List CerbMem.AbsByte) (ρ : EnvStack)
    (hstatic : is_dynamic kind = false) :
    AtomicStep M (killExpr loc ann kind pv) ρ 1
      (pointsToCell M.tagDefs (GF := GF) pv (.own 1) ty bs)
      (fun w => iprop(⌜w = SpikeVal.pure Vunit⌝ ∗
        ∃ (id a : Int), ⌜pv = cellPtr id a⌝ ∗ deadObj M.tagDefs id a ty))

theorem wps_kill {Ψ : SpikeVal → EnvStack → IProp GF}
    (loc : CerbLocation.Loc) (ann : core_run_annotation) (kind : kill_kind)
    (pv : CerbMem.PointerValue) (ty : ctype) (bs : List CerbMem.AbsByte) (ρ : EnvStack)
    (hstatic : is_dynamic kind = false) :
    iprop(pointsToCell M.tagDefs (GF := GF) pv (.own 1) ty bs ∗
      ((∃ (id a : Int), ⌜pv = cellPtr id a⌝ ∗ deadObj M.tagDefs id a ty) -∗
        Ψ (SpikeVal.pure Vunit) ρ)) ⊢
      wps M Ls Ψ (killExpr loc ann kind pv) ρ

    (pv : CerbMem.PointerValue) (ty : ctype) (bs : List CerbMem.AbsByte) (ρ : EnvStack)
    (hstatic : is_dynamic kind = false) :
    iprop(pointsToCell M.tagDefs (GF := GF) pv (.own 1) ty bs ∗ Ψ (SpikeVal.pure Vunit) ρ) ⊢
      wps M Ls Ψ (killExpr loc ann kind pv) ρ

    (pv : CerbMem.PointerValue) (ty : ctype) (bs : List CerbMem.AbsByte) (ρ : EnvStack)
    {k : Nat} (hk : 2 ≤ k) (hstatic : is_dynamic kind = false) :
    iprop(pointsToCell M.tagDefs (GF := GF) pv (.own 1) ty bs ∗

        Ψ (SpikeVal.pure Vunit) ρ)) ⊢
      wpt M Ls k Ψ (killExpr loc ann kind pv) ρ

theorem wpt_kill_emp … (hk : 2 ≤ k) (hstatic : is_dynamic kind = false) :

    (loc : CerbLocation.Loc) (ann : core_run_annotation) (kind : kill_kind)
    (pe : generic_pexpr Unit sym) (ρ : EnvStack)
    {pv : CerbMem.PointerValue}
    (hnv : valueFromPexpr pe = none)
    (hv : evalPexpr M.tagDefs M.extern ρ pe = some (Vobject (OVpointer pv))) :
    wps M Ls Ψ (killExpr loc ann kind pv) ρ ⊢
      wps M Ls Ψ (killOpRedex loc ann kind pe) ρ

theorem wpt_kill_eval … {k : Nat} (hnv …) (hv …) :
    wpt M Ls k Ψ (killExpr loc ann kind pv) ρ ⊢
      wpt M Ls (k + 1) Ψ (killOpRedex loc ann kind pe) ρ
```
Design points, as decided: (a) generic in `kind` with `hstatic : is_dynamic
kind = false` (the engine discards the type payload — pinning `Static0 ty`'s
`ty` to the cell's type would be an invented obligation); (b) the post is
`deadObj` in the atomic spec (the brief's preference) with the `emp` forms
DERIVED (`wps_kill_emp`/`wpt_kill_emp` drop the dead cell by affinity) —
never `allocMeta`/`locInBounds` (K1 audit); (c) the continuation is the BARE
`Vunit` (`mk_value_e Vunit`, confirmed §1), so `wpt_kill`'s budget is `2 ≤ k`
(one step + `deliveryCost (.pure Vunit) = 1`, as `wpt_create`) and NO `_plain`
form is needed — there is no footprint annotation to be insensitive to; (d)
the byte fragments are DROPPED, sound because `killM` leaves the bytemap
alone (`CohG.bytes` is about `σ.bytemap`, which does not change) and
addresses are never reused (`lastAddress` only descends; the dead cell keeps
its address, so `cur_meta_lo`/`metas_disj` transfer) — `CohG.kill`; (e) ONE
proof: `kill_atomic` against `Step.kill_canonical`/`Step.kill_inv` and
`killM_success`, the ghost step `metaHeap_update` then `metaOwn_persist`, the
state interpretation re-established by `CohG.kill`; `wps_kill`/`wpt_kill` are
`wps_of_atomic`/`wpt_of_atomic` corollaries; the `_eval` forms are the
`load_eval` shapes (`wpt_kill_eval` by `wpt_det_step`). Persistence/dispose
interplay (design note §1(d)): holding `allocMeta`/`locInBounds` of the cell
forecloses the kill (`.own 1 ∗ .discard` invalid) — no "alive" side
condition anywhere.
