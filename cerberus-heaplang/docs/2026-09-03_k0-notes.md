## 1. The invariant, verbatim (Heap.lean, section "The global memory well-formedness invariant")

```lean
/-- Range disjointness of two allocation records (the allocation-table
    analogue of `cellsDisjoint`/`metaDisjoint`). -/
def allocDisjoint (a b : Allocation) : Prop :=
  a.base + a.size ≤ b.base ∨ b.base + b.size ≤ a.base

structure MemWF (σ : Mem) : Prop where
  /-- every live allocation id is below the next id -/
  live_lt : ∀ id al, σ.allocations.get? id = some al → id < σ.nextAllocId
  /-- every dead allocation id is below the next id -/
  dead_lt : ∀ id, σ.deadAllocations.contains id = true → id < σ.nextAllocId
  /-- live and dead ids are disjoint -/
  live_dead : ∀ id al, σ.allocations.get? id = some al →
    σ.deadAllocations.contains id = false
  /-- all live allocations are pairwise range-disjoint -/
  disj : ∀ i j ai aj, i ≠ j → σ.allocations.get? i = some ai →
    σ.allocations.get? j = some aj → allocDisjoint ai aj
  /-- every live base is at or above the downward cursor -/
  cursor_lo : ∀ id al, σ.allocations.get? id = some al → σ.lastAddress ≤ al.base
  /-- sizes are non-negative (`allocateRegion` admits zero) -/
  size_nonneg : ∀ id al, σ.allocations.get? id = some al → 0 ≤ al.size
  /-- the cursor respects the machine address bound -/
  la_wf : σ.lastAddress ≤ 2 ^ 64
  /-- every dynamic address is at or above the cursor -/
  dyn_lo : ∀ a, a ∈ σ.dynamicAddrs → σ.lastAddress ≤ a
  /-- no dynamic address lies strictly inside a live allocation -/
  dyn_disj : ∀ a, a ∈ σ.dynamicAddrs → ∀ id al, σ.allocations.get? id = some al →
    a ≤ al.base ∨ al.base + al.size ≤ a
```

## 5. `create_fresh_global`, verbatim

```lean
theorem create_fresh_global (tds : CerbTags.TagDefsMap) (σ : Mem) (alignN : Int) (ty : ctype)
    (hwf : MemWF σ) (hsz : 0 < sizeofCtype tds ty)
    (hnz : freshBase σ.lastAddress alignN (sizeofCtype tds ty) ≠ 0) :
    σ.allocations.get? σ.nextAllocId = none ∧
    σ.deadAllocations.contains σ.nextAllocId = false ∧
    ∀ id al, σ.allocations.get? id = some al →
      freshBase σ.lastAddress alignN (sizeofCtype tds ty) + (sizeofCtype tds ty : Int) ≤ al.base :=
  ⟨hwf.fresh_alloc _ (Int.le_refl _), hwf.fresh_dead _ (Int.le_refl _),
   fun id al hg => Int.le_trans (freshBase_add_le tds _ _ _ hsz hnz) (hwf.cursor_lo id al hg)⟩
```

The premises are exactly `allocateObject_success`'s guards plus the
invariant; `allocateObject_success` mints `cellPtr σ.nextAllocId
(freshBase …)` with size `sizeofCtype tds ty`, so the third conjunct is
`allocDisjoint` (by `Or.inl`) of the minted record with EVERY live
record of σ, tracked by the logic or not.

## 7. Corrections to the charter, by measurement

- `size_pos` (design note §3) is NOT an engine invariant: `allocateRegion`
  takes `size := sizeN.toNat` (CerbMem.lean:1538) and admits zero
  (`malloc(0)`); only `allocateObject` pads to `≥ 1` (:1510). Stated:
  `size_nonneg`. Nothing in the logic needed positivity (the rules pin
  `size = sizeofCtype tds ty` with `0 < sizeofCtype` on the rule).
- The brief's dynamic-address premise — "`killM`'s dynamic arm removes
  the address" — is FALSE: `killM`'s success arm updates only
  `deadAllocations` and `allocations` (:1576-1578); the dynamic arm
  READS `dynamicAddrs` (:1573); the only writer in the file is
  `allocateRegion`'s prepend (:1548). Consequently "every address in
  `dynamicAddrs` is the base of a live allocation" fails after
  `alloc; free`, and `Nodup` fails after two zero-size regions at
  alignment 1 (same `alignedAddr`, pushed twice). What the engine
  maintains is `dyn_lo` and `dyn_disj` (§1); K3's `free` rule will take
  "this allocation is dynamic" from the metadata cell (the note's §2
  flag), with a `MetaCoh` clause tying it to `dynamicAddrs` — not from
  the global invariant.
- The brief's "prove from the existing `_layer` lemmas" for
  `storeM`/`loadM`: `storeM_layer`/`loadM_layer` (Round.lean) say only
  "active or killed" and carry no state; and Round imports Heap, not
  the reverse. Preservation is proved directly on the unfolded
  operations under `applyMemM` (the same case split the `_layer` proofs
  use), in Heap.lean, for every active outcome — which is the stronger
  and the placeable statement.
- `MemWF.alloc` needs no positivity of the base (`hpos` was dropped as
  unused): `cursor_lo`/`disj` follow from `base + size ≤ lastAddress`
  and `0 ≤ size` alone.
