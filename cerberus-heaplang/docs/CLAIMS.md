# The claim matrix

HAND-WRITTEN PROSE, stated as such (ar5-manifest, 2026-09-04 — the external
audit's remediation 6, `../../docs/2026-09-04_reynolds-ohearn-separation-logic-audit.md`;
record `2026-09-04_ar5-manifest-notes.md`). For every headline claim of this
package: the exported theorem(s), the kind of statement, the exhibits that
demonstrate it, the operation variants it supports (pointing at the rows of
[the rule-use and classification manifest](CAPABILITY_MANIFEST.md)), the
known exclusions (pointing at `../../docs/KNOWN-OPEN-ITEMS.md`, "KOI" below)
and the check that keeps the row fresh.

WHAT IS MACHINE-CHECKED HERE, AND NOTHING ELSE: `scripts/capability_manifest.lean`
(run by the full gate) parses every table row whose first cell begins `C<n>` and checks
that each backticked name in the SECOND cell ("Exported theorem(s)") is a
theorem, definition or inductive of the built environment — a renamed or deleted export
turns the manifest red until this file is updated. The prose in the other
cells is reviewed, not checked. Axiom sets: every name below that Audit.lean
pins is trio-exact by the build (gate 2); this file does not repeat the pin
list.

Kinds: **partial** — a statement about the shipped driver's per-thread loop
at every fuel (delivery or `CerbND.fuelExhaustedKill`, never a kill
otherwise); **total** — a closed equation about the shipped pipeline's
result; **projected** — an Iris-free memory/execution statement obtained from
a proved Iris triple; **semantic** — a fact about the engine or the mirror
with no logic in its statement; **rule** — a proof rule of a judgment.
