## 1. M-1 — the distinctness laws (verbatim, Heap.lean, after `metaOwn_ne`)

Both are `metaOwn_ne` (`metaOwn i₁ (.own 1) mc₁ -∗ metaOwn i₂ dq₂ mc₂ -∗
⌜i₁ ≠ i₂⌝`) at the region bundles: the left side is at `.own 1`, the
right at ANY fraction — including `.discard`, which is what `deadRegion`
holds. Pinned (Audit.lean, 294 → 296); API.lean "Assertion laws" row.

```lean
/-- REGION DISTINCTNESS: a fully-owned live region and any region
    ownership (any fraction) are of different allocation ids. -/
theorem regionOwn_ne (id id' a a' : Int) (n n' : Nat) (dq' : DFrac)
    (bs bs' : List CerbMem.AbsByte) :
    iprop(regionOwn (GF := GF) id a n (.own 1) bs ∗ regionOwn id' a' n' dq' bs') ⊢
      (⌜id ≠ id'⌝ : IProp GF) := by
  unfold regionOwn
  iintro ⟨⟨Hm, -, -⟩, Hm', -, -⟩
  ihave %hne := metaOwn_ne $$ Hm [Hm']
  · iexact Hm'
  ipureintro
  exact hne

/-- LIVE AND DEAD ARE DISTINCT: a fully-owned live region and the
    persistent knowledge of a dead one are of different allocation ids. -/
theorem regionOwn_deadRegion_ne (id id' a a' : Int) (n n' : Nat)
    (bs : List CerbMem.AbsByte) :
    iprop(regionOwn (GF := GF) id a n (.own 1) bs ∗ deadRegion id' a' n') ⊢
      (⌜id ≠ id'⌝ : IProp GF) := by
  unfold regionOwn deadRegion
  iintro ⟨⟨Hm, -, -⟩, Hd⟩
  ihave %hne := metaOwn_ne $$ Hm [Hd]
  · iexact Hd
  ipureintro
  exact hne
```

`deadRegion_ne` (two dead regions) is NOT derivable and was not added:
both are `.discard`, persistent and duplicable — `deadRegion id a n ⊢
deadRegion id a n ∗ deadRegion id a n` — so no law can separate them.
Distinctness of the dead ids is therefore CARRIED from the time they were
live (§2). The brief's question "is the alloc-side distinctness against
DEAD regions derivable from the public laws?" — YES: `wps_alloc`/`wpt_alloc`
deliver the fresh region at `.own 1`, and `regionOwn_deadRegion_ne` against
each `deadRegion` of `deadRegions done` gives `id ∉ done`; no freshness
argument about `nextAllocId` is needed, the ghost metadata heap's
exclusivity does it. No obstacle; no fallback to option (b).

### The lifts (MallocListExhibit.lean, section RegionList)

`regionOwn_isRegionList_ne id a bs : ∀ p ids, regionOwn id a 16 (.own 1)
bs ∗ isRegionList p ids ⊢ ⌜id ∉ ids⌝` and `regionOwn_deadRegions_ne id a bs
: ∀ ids, regionOwn id a 16 (.own 1) bs ∗ deadRegions ids ⊢ ⌜id ∉ ids⌝`, by
structural recursion over the list (the `deadRegions_dead` pattern): at
each node the pure `id ≠ id'` is read off non-destructively via
DisposeExhibit's `keep_pure` and the recursion continues on the tail. Both
destructive (pure conclusion); the call sites wrap them in `keep_pure` to
keep the region and the list. Unpinned exhibit internals (as
`deadRegions_dead`), covered by the sweep.

### How the `Nodup` is discharged (both strata, identically)

- BUILD (`i > 0`): after `wps_alloc` delivers `regionOwn id a 16 (.own 1)
  regionUndef16`, `keep_pure (regionOwn_isRegionList_ne …)` against
  `isRegionList pc ids` yields `id ∉ ids`, `keep_pure
  (regionOwn_deadRegions_ne …)` against `deadRegions done` yields `id ∉
  done`; at the jump `((id :: ids) ++ done).Nodup` is
  `List.nodup_cons.mpr ⟨List.not_mem_append hnotin hnotin', hnd⟩`.
- FREE, node (`i = 0`, `ids = id :: ids'`): the head moves from the live
  list to the dead one — `(ids' ++ id :: done).Nodup` from `(id :: (ids' ++
  done)).Nodup` by `List.pairwise_middle` (`Nodup` is `Pairwise (· ≠ ·)`,
  symmetric). PURE: no Iris law is needed at the free — the distinctness
  was established when the node was allocated.
- FREE, null: `([] ++ done).Nodup` is `done.Nodup`, the post's conjunct.
- Entry (`ml_wps`/`ml_wpt`): `(([] : List Int) ++ []).Nodup` by `simp`.

`mlPost_readout` carries `ids.Nodup` through `stateInterp_readout`
unchanged (a pure conjunct beside the length); the two engine-facing
proofs destructure one more component.
