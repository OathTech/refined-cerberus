```lean
    (loc : CerbLocation.Loc) (ann : core_run_annotation)

    (loc : CerbLocation.Loc) (ann : core_run_annotation)
    (aprov sprov : CerbMem.Provenance) (alignN sizeN : Int)
    (pref : prefix0) (ρ : EnvStack) {k : Nat} (hk : 2 ≤ k)
    (hcost : 0 < regionCost alignN sizeN) :
    iprop(allocBudget (GF := GF) (regionCost alignN sizeN) ∗
      (∀ (id a : Int),
        (regionOwn id a sizeN.toNat (.own 1) (List.replicate sizeN.toNat undefByte) ∗
          ⌜0 < a ∧ a + (sizeN.toNat : Int) ≤ 2 ^ 64⌝) -∗
        Ψ (SpikeVal.pure (Vobject (OVpointer (cellPtr id a)))) ρ)) ⊢
      wpt M Ls k Ψ (allocExpr loc ann (.IV aprov alignN) (.IV sprov sizeN) pref) ρ

theorem wpt_alloc_eval … {k : Nat} (hnv …) (hv1 …) (hv2 …) :
    wpt M Ls k Ψ (allocExpr loc ann align size pref) ρ ⊢
      wpt M Ls (k + 1) Ψ (allocOpRedex loc ann pe1 pe2 pref) ρ

theorem wpt_free {Ψ : SpikeVal → EnvStack → IProp GF}
    (loc : CerbLocation.Loc) (ann : core_run_annotation) (kind : kill_kind)
    (id a : Int) (n : Nat) (bs : List CerbMem.AbsByte) (ρ : EnvStack)
    {k : Nat} (hk : 2 ≤ k) (hdyn : is_dynamic kind = true) :
    iprop(regionOwn (GF := GF) id a n (.own 1) bs ∗
      (deadRegion id a n -∗ Ψ (SpikeVal.pure Vunit) ρ)) ⊢
      wpt M Ls k Ψ (killExpr loc ann kind (cellPtr id a)) ρ

theorem wpt_free_emp … {k : Nat} (hk : 2 ≤ k) (hdyn : is_dynamic kind = true) :
    iprop(regionOwn (GF := GF) id a n (.own 1) bs ∗ Ψ (SpikeVal.pure Vunit) ρ) ⊢
      wpt M Ls k Ψ (killExpr loc ann kind (cellPtr id a)) ρ
```
Design points, as decided: (a) the alloc post carries the pointer as `cellPtr
id a` with `id a` existential (rather than `∃ p, ⌜w = ptr p⌝ ∗ … pv-shaped
bundle`): `regionOwn` is indexed by id and base (K1), and the free rule's
precondition is stated at `killExpr … (cellPtr id a)` — so `lets p = alloc(…)
in free(p)` composes by binding `Vobject (OVpointer (cellPtr id a))` with no
intermediate `∃`-unpacking (`alloc_free_wps`). (b) The bounds are `0 < a ∧ a
+ size ≤ 2^64` — the whole region inside the address space; at size 0 the
create-style `a < 2^64` is NOT derivable (`la_wf` is `≤ 2^64`), and the sum
form is the stronger statement at every positive size. (c) `hcost : 0 <
regionCost alignN sizeN`: at cost 0 the budget fragment is `◯ 0`, the unit,
which cannot force the cursor cell of `budgetInterp`'s right disjunct, so
nothing about `lastAddress` is known and the OOM arm cannot be excluded —
the premise is exactly the condition under which the budget speaks. It holds
at every positive size (`regionCost_pos`) and at size 0 whenever the
alignment is ≥ 2; the one shape outside the rule is `alloc(al, 0)` at `al ≤
1`, classified by `complete_alloc`. (The alternative — requiring `0 <
sizeN`, the orchestrator's option (a) — would have excluded the size-0
regions the `la_pos` clause was added to price; both are recorded here.) (d)
`free_atomic`'s post is `deadRegion` (K1's bundle; the `_emp` faces drop it
by affinity), the `kind` is generic with `hdyn : is_dynamic kind = true`
(`Dynamic0` is the only dynamic kind, but the engine reads only the Bool —
K2's design point (a) mirrored). (e) The free operand form is the existing
kind-generic `wps_kill_eval`/`wpt_kill_eval` — no alias theorem was added
(a `wps_free_eval := wps_kill_eval` would be a second name for one
statement); the consumers use `wps_kill_eval … Dynamic0 …`. (f) ONE proof
each: `alloc_atomic` is `create_atomic`'s proof with `allocateRegion_success`/
`CohG.alloc`/`freshBase_ne_zero_of_cost'`/`headroom_freshBase'` and the
`la_pos` read-off; `free_atomic` is `kill_atomic`'s with `killM_success_dynamic`
and `regionCell`; the strata faces are `wps_of_atomic`/`wpt_of_atomic`
corollaries, the `_eval` forms the `store_eval` shapes. One proof-engineering
note: in `alloc_atomic` the successor-state equation must be extracted with
`simp only [Prod.mk.injEq] at hout` (kill_atomic's shape), not `simpa … using
hout` — `simpa` normalizes `↑sizeN.toNat` to `max sizeN 0` and the state no
longer matches `CohG.alloc`'s statement syntactically.

## 6. THE N-2 DECISION: the static kill of a region has NO rule (and three companions)

The K2 range audit's N-2: the fragment admits, and the engine ACCEPTS, a
STATIC kill of a live DYNAMIC region — `killM` short-circuits the :1573 check
at `isDynamic = false`. [AGENT] decision at K3, recorded on every surface
(Soundness.lean `Frag.kill` docstring, README "Scope, exactly", WALKTHROUGH
§4/§7): it is in the fragment (`Frag.kill` carries no kind premise since K3),
mirrored (`Step.kill`), classified (`complete_kill`), and covered by NO rule —
`kill_atomic`'s precondition is the OBJECT bundle `pointsToCell` (a created,
typed cell, `dynamic := false`), `free_atomic`'s is the REGION bundle
`regionOwn` (an `alloc`ated, untyped cell, `dynamic := true`), and the
metadata cells agree on the flag (`metaOwn_agree`), so no derivation reaches
the cross case. A program that static-kills a region — C's freeing malloc'd
storage as if it were automatic — is OUTSIDE the logic by design; we do not
prove such programs, and soundness is unaffected (a rule not stated). The
companions, likewise in the fragment, classified, and without a rule: `free`
of a CREATED object (UB179a unless the base happens to sit in `dynamicAddrs`
— the K0 audit's N-1 scenario; the logic never reads that list), `free(NULL)`
(the engine's no-op; nothing to consume or produce), and the zero-COST
`alloc(al, 0)` at `al ≤ 1` (§4(c)). The two rules together are exactly
Reynolds/O'Hearn's cons/dispose over regions plus C's automatic storage over
objects, with the engine's kind discipline made visible as two bundles.
