**Why a separate triple, not `MemTripleU` with a side condition.** The
launch premise genuinely differs: `engine_adequacyU_alloc` launches
through `launchResources`, which needs `LaunchCoh M.tagDefs σ (P ∪ R)
reqs` — `Sat` (its `coh` field) PLUS `id_lt`/`fresh_alloc`/`fresh_dead`
(every id from `nextAllocId` up is untracked, unallocated, not dead),
`addr_lo` (footprint cells at or above `lastAddress`), `plan`
(`PlanFits` at the actual cursor) and `la_wf` (`lastAddress ≤ 2^64`)
(Adequacy.lean:442-458). None follows from `Sat`: a memory can carry the
footprint with its cursor sitting on top of those cells, and `create`
would then be unsafe. The frame stays inside the definition (`R`
returned to the post), the post is `project_triple`'s verbatim, and
`MemTripleU` implies `MemTripleU_alloc` at every plan (the bridge
lemma; the converse fails). Proof of the projection: `engine_adequacyU_alloc`
at the seeded footprint `P ∪ R` (`BigSepM.bigSepM_union` splits the
cells, the capacity rides alongside), `spike_wp_wand`, then the same
`stateInterp_readout ∘ consequences_intro` as `project_triple`.

**Consumer.** `struct_create_store_adequacy` (StructExhibit.lean:807),
statement unchanged (the `MemTripleU_alloc` body at `spikeCtx`,
footprint `∅`, frame `∅`, plan `[⟨8, structTy⟩]`, memory `prodMem₀`):
`project_triple_alloc` with `Q` := the post of `struct_create_store_wps`
(collapsed by `blockSpecs_intro`+`wps_sound`), `LaunchCoh` from
`prodMem₀_launchCoh` after `union_empty_right`, and the projected
obligation discharged by `exists_consequence` ∘ `sep_consequence
(pure_consequence _) (sep_consequence (pointsToCell_consequence …)
(BI.pure_intro True.intro))` after dropping the empty frame's `[∗map]`
(`bigSepM_empty`, `emp_sep`). Consequence for the tree:
`spike_engine_adequacy_alloc` (Adequacy.lean) no longer has a consumer
in the package (it was this theorem's launcher); it stays as the
spike-profile face of `engine_adequacyU_alloc`, which
`project_triple_alloc` now consumes directly — flagged here, not
removed (no statement change in this slice).

**A production export through it — not possible, and why.** The
production exports (`exhibitA_prod`, `*_certified_production`) are
unconditional `runND … = [(Active dres, [], dst')]` EQUATIONS reached
through the TOTAL lane (`wpt_driver_done_alloc` → `prod_run_eqJ`); a
`MemTripleU`/`MemTripleU_alloc` conclusion is partial correctness
(`.done ⇒ post`, `.more` unconstrained) and cannot yield an equation.
The allocating projection's consumer is therefore the partial-lane
struct client; the total lane's allocating face remains
`wpt_engine_boundU/J_alloc` with `readoutPost`, as before.

```lean
import CerberusHeapLang
open Lean

/-- transitive constant closure of a declaration (types + values;
    opaque bodies traversed — the `collectAxioms` convention) -/
partial def closure (env : Environment) (roots : List Name) : NameSet := Id.run do
  let mut seen : NameSet := {}
  let mut stack := roots
  while !stack.isEmpty do
    let n := stack.head!
    stack := stack.tail!
    if seen.contains n then continue
    seen := seen.insert n
    match env.find? n with
    | none => pure ()
    | some ci =>
      let mut cs := ci.type.getUsedConstants
      match ci.value? (allowOpaque := true) with
      | some v => cs := cs ++ v.getUsedConstants
      | none => pure ()
      match ci with
      | .inductInfo iv => cs := cs ++ iv.ctors.toArray
      | _ => pure ()
      for c in cs do
        if !seen.contains c then stack := c :: stack
  return seen

#eval show CoreM Unit from do
  let env ← getEnv
  let exports := CerberusHeapLang.Audit.trioExports
  let mut table : Std.HashMap Name (List Name) := {}
  for ex in exports do
    let cl := closure env [ex]
    for c in cl.toList do
      match env.find? c with
      | some (.opaqueInfo _) | some (.axiomInfo _) =>
        table := table.insert c (ex :: (table.getD c []))
      | _ => pure ()
  let rows := table.toList.map (fun (c, exs) =>
    let m := match env.getModuleIdxFor? c with
      | some i => env.header.moduleNames[i.toNat]!.toString
      | none => "<local>"
    (c.toString, m, exs.length))
  let rows := rows.toArray.qsort (fun a b => (a.2.1 ++ " " ++ a.1) < (b.2.1 ++ " " ++ b.1))
  IO.println s!"exports: {exports.length}"
  for (c, m, k) in rows do
    IO.println s!"{m} :: {c} :: reached by {k} exports"
```
