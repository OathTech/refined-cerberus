## 2. The mirror (Step.lean), verbatim

```lean
def callRedex? : CoreExpr → Option (context × sym × List (generic_pexpr Unit sym))
  | Expr _ (Eproc _ (Sym f) pes) => some (CTX, f, pes)
  | Expr a (Esseq pat e1 e2) => (callRedex? e1).map fun q => (Csseq a pat q.1 e2, q.2)
  | Expr a (Ewseq pat e1 e2) => (callRedex? e1).map fun q => (Cwseq a pat q.1 e2, q.2)
  | Expr a (Eannot ds b) =>
      if annotRooted b then none else (callRedex? b).map fun q => (Cannot a ds q.1, q.2)
  | _ => none

def lookupProc (file : generic_file Unit core_run_annotation) (ext : Fmap sym sym)
    (f : sym) : Option (List (sym × core_base_type) × CoreExpr) :=
  match fmapLookupBy (fun (s1 : sym) (s2 : sym) => Lem_Basic_classes.ordCompare s1 s2)
      f file.stdlib with
  | some (Proc _ _ _ params body) => some (params, body)
  | _ =>
    match fmapLookupBy (fun (s1 : sym) (s2 : sym) => Lem_Basic_classes.ordCompare s1 s2)
        (resolveExtern ext f) file.funs with
    | some (Proc _ _ _ params body) => some (params, body)
    | _ => none

def procEnv (params : List (sym × core_base_type)) (vs : List value) : Fmap sym value :=
  foldl2 (fun (acc : Fmap sym value) (p : (sym × core_base_type)) (cval : value) =>
      match acc, p, cval with
      | acc, (sym1, _), cval =>
        fmapAddBy (fun (s1 : sym) (s2 : sym) => Lem_Basic_classes.ordCompare s1 s2)
          sym1 cval acc)
    fmapEmpty params vs

def callRedex (ra : core_run_annotation) (f : sym)
    (pes : List (generic_pexpr Unit sym)) : CoreExpr :=
  Expr [] (Eproc ra (Sym f) pes)

  | call {e : CoreExpr} {ctx : context} {f : sym} {pes : List (generic_pexpr Unit sym)}
      {params : List (sym × core_base_type)} {body : CoreExpr} {vs : List value}
      {ρ : EnvStack} {ctl : Ctl} {σ : Mem}
      (hc : callRedex? e = some (ctx, f, pes))
      (hvs : evalPexprs M.tagDefs M.extern ρ pes = some vs)
      (hf : lookupProc M.file M.extern f = some (params, body))
      (hlen : params.length = vs.length) :
      Step M (e, ρ, ctl, σ)
           (body, procEnv params vs :: ρ,
            ⟨(ctl.proc, ctx) :: ctl.κ, some f, push_exec_loc f M.currentLoc ctl.execLoc⟩, σ)
  | ret {v : value} {ev0 : Fmap sym value} {evs : List (Fmap sym value)}
      {p : Option sym} {ctx : context} {κ : List (Option sym × context)}
      {q : Option sym} {ℓ : exec_location} {σ : Mem} :
      Step M (Expr [] (Epure (Pexpr [] () (PEval v))), ev0 :: evs, ⟨(p, ctx) :: κ, q, ℓ⟩, σ)
           (apply_ctx ctx (Expr [] (Epure (Pexpr [] () (PEval v)))), evs, ⟨κ, p, ℓ⟩, σ)
  | ret_annot {ds : List dyn_annotation} {v : value} {ρ : EnvStack}
      {pc : Option sym × context} {κ : List (Option sym × context)}
      {q : Option sym} {ℓ : exec_location} {σ : Mem} :
      Step M (Expr [] (Eannot ds (Expr [] (Epure (Pexpr [] () (PEval v))))), ρ,
              ⟨pc :: κ, q, ℓ⟩, σ)
           (Expr [] (Epure (Pexpr [] () (PEval v))), ρ, ⟨pc :: κ, q, ℓ⟩, σ)
```

THE CAPTURING DISCIPLINE — the exact shape. `Step.call` is stated at the
WHOLE expression, like `Step.run`: `callRedex? e = some (ctx, f, pes)`
names the call redex at the spine hole AND the context get_ctx pairs it
with, built outside-in exactly as get_ctx builds it (§1: `Csseq a pat ·
e2` at an `Esseq` node, `Cwseq …`, `Cannot a ds ·` under the guarded
annotation descent). The engine captures that context onto the stack
(`stack0 := Stack_cons2 th_st.current_proc_opt ctx th_st.stack0`); the
mirror pushes `(ctl.proc, ctx)` on `κ`. Certification of the search
against the engine's decomposition: `Decomp.callRedex?_some : Decomp e
ctx (callRedex ra f pes) → callRedex? e = some (ctx, f, pes)` and its
inverse `Decomp.callRedex?_inv : Decomp e ctx r → callRedex? e = some
(ctx', f, pes) → ctx' = ctx ∧ ∃ ra, r = callRedex ra f pes`; the two
spine searches are exclusive (`callRedex?_none_of_jumpRedex?_some`).
`Decomp.step_factor` gains the THIRD DISJUNCT: a step of a decomposed
term is a redex step REBUILT in context (preserving; the redex now
provably neither a run nor a call redex), OR the jump (discarding), OR
the call, whose successor is `(body, procEnv params vs :: ρ, ⟨(ctl.proc,
ctx) :: ctl.κ, some f, push_exec_loc f M.currentLoc ctl.execLoc⟩, σ)`
with `ctx` the DECOMPOSITION's context (capturing). The frame inversions
`Step.sseq_inv`/`wseq_inv`/`annot_inv` each gain the disjunct
`Step.CallOf M e1 (fun c => Csseq a pat c e2) …` (the call of the
sub-expression with the frame captured), `annot_inv` also the REMOVE-ANNOT
disjunct; `Step.call_inv` (by induction on the step — a congruence rule
cannot frame a call, the pushed control differs from the threaded one)
is the redex-in-context inversion.

`procEnv` is `call_proc`'s `foldl2` VERBATIM (the lambda included), so
the bridge `call_proc_of_lookupProc : lookupProc file ext f = some
(params, body) → params.length = vs.length → call_proc ext file f vs =
except_return (procEnv params vs, body)` is `call_proc_eq` plus the Lem
`BEq` fact; `call_proc_unknown`/`call_proc_arity` are the two kills.

THE RETURN's env premise `ev0 :: evs` excludes the engine's empty-env
`failwithI` (a frame is on the env stack whenever the call stack is
non-empty: the call pushed both). `exec_loc` is not popped (`ℓ` rides).

## 3. Design corrections and forced changes ([AGENT], each with its forcing fact)

(a) THE JUDGMENTS' GUARD — `wps.pre`/`wpt.pre` are `⌜False⌝` at a call
redex in context (`match callRedex? e with | some _ => ⌜False⌝ | none =>
step clause`). The brief said "NO judgment changes (C3)"; this is the
minimal change FORCED by adding `Step.call` to the mirror, and it is the
shape C3 replaces (the `some` arm becomes the call clause). Forcing fact:
the C1 step clause continues `F Ψ r.e r.ρ` at the SOURCE control index
`ctl` (the C1 audit's N-3 named it), so with `Step.call` in the mirror
the C1 collapse `wps_sound` (at `hκ : ctl.κ = []`) is FALSE, not merely
unprovable — counterexample: `e := Eproc () (Sym f) []`, `f`'s body `pure
1`, `Ψ := fun w ρ' => ⌜ρ' = procEnv [] [] :: ρ⌝`; `wps M ctl Ls Ψ e ρ`
holds (the step clause's successor is `(pure 1, procEnv :: ρ, pushed
ctl)`, and `wps M ctl Ls Ψ (pure 1) (procEnv :: ρ)` is the value clause,
`Ψ (pure 1) (procEnv :: ρ) = ⌜True⌝`), while `WP ⟨e, ρ, ctl, M⟩ {{ w, Ψ
w.w w.ρ }}` fails: the only run is call → `Step.ret` → the value `pure 1`
AT ENV `ρ` (popped), so the post is `⌜ρ = procEnv :: ρ⌝`, false. Under the
guard every judged configuration's step is control-preserving
(`Step.ctl_eq hs hcr htv`), which is what the collapses need. Every rule
proof supplies the guard fact (`rfl` at a known redex; a case split
`cases hcr : callRedex? e` in the structural lemmas, the `some` branch
closed by `⌜False⌝`); `wps_of_atomic`/`wpt_of_atomic`/`wpt_det_step` gain
the premise `hnc : callRedex? e = none` (`rfl` at every call site);
`wpt_step_eq`/`wpt_zero_step_eq` gain `hcr`, and `wpt_call_eq` is the
guard's equation. The snapshot does not see this change (the TYPES of
`wps.pre`/`wpt.pre` are unchanged; §8 lists it separately).

(b) `Step.ret_annot` — REMOVE-ANNOT at a non-empty stack. The design
note's Q3 has `ret` only; the engine's REMOVE-ANNOT arm (§1, col 2990)
fires at ANY stack before the value arm's RETURN branch is reached, and at
`κ ≠ []` the annotated value is a non-terminal for the Language (C1's
`toValRt`), so without this step a `{A}v` under a frame would be
mirror-STUCK where the engine steps — a completeness hole
(`complete_ret` covers both value forms). At `κ = []` no rule fires on a
value (the value protocol, `Step.val_elim hκ`).

(c) THE CONGRUENCE GUARD `toVal e1 = none` on `Step.sseq_ctx`/`wseq_ctx`.
Forcing fact: get_ctx descends into `e1` only when `is_irreducible e1 =
false` (§1); before C2 the guard was derivable (no rule stepped a value —
"No irreducibility guard is needed", the C1 docstring) and is now
LOAD-BEARING: `ret_annot` steps `{A}v` WITHOUT changing the control, so
an unguarded `sseq_ctx` would lift it to `Esseq pat {A}v e2 → Esseq pat v
e2` — a step the engine never takes (at that node the root IS the
LETS-ANNOT redex) — and `engine_step_matchU` would be false. `Step.call`
and `Step.ret` change the control, so they were never instances of the
congruence premise; `annot_ctx` needs no guard (its `annotRooted b =
false` premise already excludes the annotated value). Consequences: the
frame disjunct of the inversions carries `toVal e1 = none`; the ~30
former `Step.val_elim` dismissals at framed values become `rw
[toVal_ofVal] at hnv'; cases hnv'`; `Decomp.lift_step` supplies
`hd.toVal_none`.

(d) THE CONTROL LEMMAS. `Step.ctl_eq`/`ctl_eq'`/`retag` (every step
preserves the control) are FALSE with calls; they now take the two
guards `callRedex? e = none` and `toVal e = none` (exactly the sources of
`call` and `ret`/`ret_annot`); the case analysis `Step.ctl_cases` (same
control ∨ the call's data ∨ the return's data) is the general fact.
`Step.val_elim`/`Step.toVal_none` take `hκ : ctl.κ = []` (a value steps
under a frame); `Step.toValRt_none` is the Language's `val_stuck` at
every control; `Step.pure_val_elim`/`Step.annot_val_inv` are the
same-control value facts the `Frag`-induction sweeps use;
`Step.env_cons'` takes `c'.2.2.1 = c.2.2.1` (the call pushes a frame,
the return pops one — cons-shape with the SAME tail holds only across
control-preserving steps; `Step.env_cons` unchanged). `Step.pure_inv`
takes `valueFromPexpr pe = none` (a bare value under a frame IS a step,
the return). `RoundClass.value_not_step` takes `hκ`. `Step.memop_vals_inv`
(new) replaces four raw `cases hs` on the PtrEq-at-values step, which
now fail dependent elimination (the call constructor's target control).

(e) `MachineCtx.FragProcs` AS AN ADEQUACY PREMISE, and the drive
classification THROUGH calls. The brief asked where the callee-body
premise lives — decided: NOT on `Frag` (a predicate on the expression;
the body is in the FILE), NOT needed by the certification or the
completeness (the engine's PCALL round installs any body), but REQUIRED
by the `driveU` adequacy lane NOW, not in C3: `engine_adequacyU` & co.
take their NotStuck oracle from the RAW Iris WP (`spike_step_adequacy`),
which does not exclude a call redex — with `Frag.call` in the fragment
the drive classification `drive_classifyU` (C1: fixed control, `Step.ctl_eq`
at every step) is unprovable, and a call CAN be reached (a hand-built
`WP` at a call configuration is provable; `wps`-derived WPs never reach
one, by the guard). So: `structure MachineCtx.FragProcs (M) : Prop` —
`body`: every declared procedure (`lookupProc M.file M.extern f = some
(params, body)`) has `Frag body`; `potBound`: `pot body ≤ lemDefaultFuel`;
`labels`: its label fiber `M.labelsAt (some f)` has `Frag` bodies within
the bound (the callee's jumps read the LIVE procedure) — the twin of
`hQf`/`hQpot`, per procedure. `drive_classifyU_aux` is the
control-general induction under the invariant `ControlOk M ctl` (the
current procedure's label bodies are in the cone; every saved frame
`(p, ctx)` on `κ` has label bodies in the cone and plugs a bare value into
a fragment term within the bound — `Decomp.frag_plug_call`/
`pot_plug_call_le`, by induction on the decomposition; the sym-binder
frame is impossible, its head is a `BareHead`, never a call —
`BareHead.no_call`) and the env-depth invariant `ctl.κ.length < ρ.length`
(the RETURN's cons-env premise). `drive_classifyU`'s statement is the C1
one plus `(hPf : M.FragProcs)`, proved from the aux at the entry control
(`κ = []` makes the frame invariant vacuous). The exports
`engine_adequacyU`, `engine_adequacyU_alloc`, `project_triple`,
`project_triple_pure`, `project_triple_alloc`, `project_triple_pure_alloc`,
`semantic_triple_soundU`, `semantic_frameU` gain `(hPf : M.FragProcs)`
after `hQpot`; both profiles share the default file, so the premise is
vacuous there (`lookupProc_spikeFile : lookupProc spikeFile ext f = none`
by `rfl`; `spikeCtx_fragProcs`, `procCtx_fragProcs rs`) — every exhibit
passes one of the two (16 call sites). The TOTAL lane (`wpt_drive_aux`,
`wpt_engine_boundU`, `wpt_driver_*`) needs no such premise: its oracle
is the total judgment, `⌜False⌝` at a call. Device readings for the two
new rounds: `outcomesU_of_call` (via `step_ctx_call_ws` under
`dischargeStep`'s with-runstate arm — the arm's `Exception → offFragment`
is untouched: the KILL rows live at the shipped driver, `ShippedRefusal`)
and `outcomesU_of_ret` (via `step_ctx_ret` under the tau arm).
