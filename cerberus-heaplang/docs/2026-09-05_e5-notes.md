## 3. The `bound` congruence rules were UNSOUND at the E5 fragment — the finding and the fix ([AGENT])

`wps_bound : wps … b ρ ⊢ wps … (bound b) ρ` (E1) and `wpt_bound` were
proved with `Step.bound_ctx` unguarded. With `Step.neg_bound` the `bound`
frame PERFORMS a round of its own, so `Step.bound_ctx` gains the guard
`negRedex? b = none` (the engine steps the body's redex only when it is not
a negative action). The congruence rule with the guard as a *one-shot*
premise is still unsound: the Löb induction re-enters at the body's
successor `b'`, and `b'` can acquire a negative redex (`b = case v of … =>
sseq (bound (wseq (neg act) e2')) e2` steps by `case_value` to a `b'` whose
standalone reduction is fine — the inner `bound` performs the neg round —
while `bound b'` is STUCK in the mirror and the ENGINE PANICS: the outermost
`bound`'s `break_at_sseq` meets the inner `Cbound`, :427). So `wps b'` can
hold while `wps (bound b')` is false. The premise must be step-invariant:

- `negFree : CoreExpr → Bool` (Step.lean) — no `Paction Neg0` and no
  `Eexcluded` anywhere (descends exactly where `ccallFree` does);
  `negRedex?_none_of_negFree`; preserved by every stack-preserving non-jump
  round, `Step.negFree_preserved` (Soundness.lean — the `ccallFree` lemmas'
  twins; `case_value` through the substitution shape lemma
  `negFree_subst_fold` at the engine's fuel).
- The substitution shape lemmas need `esize ≤ lemDefaultFuel` (the engine's
  `subst_sym_expr_lemFuel 0 e = fuelExhausted e`, an OPAQUE term,
  Core_aux.lean:517–519, measured this session), so a size invariant travels
  with `negFree`: `pot`. `pot` is made ADDITIVE (`Esseq/Ewseq: 1 + pot e1 +
  pot e2`, `Eif: 1 + pot e2 + pot e3`, `Ecase: 2 + potAlts` (the sum of the
  branches), `Eunseq: 2 + potList` (the empty `unseq`'s completion into the
  annotated tuple costs 2), `Elet`/`End`/`Epar: 1 + …`, `Paction Neg0: 10`
  (the rewrite's weight: `bound(let weak (_, s) = unseq(Eexcluded n act,
  ctxA'[pure(Unit)]) in pure(s))` costs the binder 1 + the `unseq` 2 + (1 +
  2) + (1 + plug) + the tail 2 = the leaf's 10 + the plug's own,
  `pot_negRewrite_le`)); `Frag.pot_le_two` (the max-era `pot ≤ 2`) is
  RETIRED; `esize_le_pot` holds for EVERY term (the fragment-free form) and
  `Step.pot_le` (fragment-free: `jumpRedex?/callRedex?/toVal = none →
  negFree e → pot e' ≤ pot e`, by induction on `Step`).
- The rules, verbatim (FORCED text change: two premises; every exhibit
  call site discharges them by `rfl` and `Nat.le_of_ble_eq_true rfl`):

  ```lean
  theorem wps_bound {Ψ : SpikeVal → EnvStack → IProp GF} (a : List annot) (b : CoreExpr)
      (ρ : EnvStack) (hnf : negFree b = true) (hpot : pot b ≤ lemDefaultFuel) :
      wps M p Ls Θ (fun w ρ' => Ψ (SpikeVal.pure w.val) ρ') b ρ ⊢
        wps M p Ls Θ Ψ (Expr a (Ebound b)) ρ

  theorem wpt_bound {Ψ : SpikeVal → EnvStack → IProp GF} (a : List annot) (b : CoreExpr)
      (ρ : EnvStack) (hnf : negFree b = true) (hpot : pot b ≤ lemDefaultFuel) {k : Nat} :
      wpt M p Ls Θ k (fun w ρ' => Ψ (SpikeVal.pure w.val) ρ') b ρ ⊢
        wpt M p Ls Θ (k + 1) Ψ (Expr a (Ebound b)) ρ
  ```

  `wps_bound` is derived from the Löb-proved `wps_bound_aux` (the two
  premises inside the entailment as `⌜negFree b = true ∧ pot b ≤
  lemDefaultFuel⌝ ∗ …`); the call plug case uses `callRedex?_apply_ctx_eq`
  (new: the call search returns the decomposition) with
  `negFree_apply_ctx_of` and `pot_apply_ctx_plug`.
- Consequence for E5's programs: a `bound` whose body contains
  `neg(store …)` has NO `wps`/`wpt` rule at this head — `wps_neg_bound`
  (slice 2) is the rule for the whole `bound(… neg …)` statement: the
  bind-through-`bound` shape cannot be compositional for such bodies.

Other FORCED text changes at frozen exports: none. `Step.ctl_upd`'s
consumers in Wps/Wpt (the eight binder rules' step cases and
`wps_sound_cps`/`wpt_sound_cps`) no longer assume the `upd` shape — the
